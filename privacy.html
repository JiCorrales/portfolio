Privacy Policy

Gmail MCP, a personal tool by Jose Corrales. Last updated November 12, 2026.

What this is

Gmail MCP is a private tool that lets Jose Corrales search his own Gmail accounts from his own computer. It is not offered to anyone else.

Data it accesses

With the account owner's consent, it reads Gmail messages using read-only access (gmail.readonly). It cannot send, delete or change email.

How data is used and stored

Messages are read on demand to answer the account owner's own questions. Access tokens are stored only on the owner's computer. No email data is sold, shared, or sent to any server run by this tool, and it is not used for advertising.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
